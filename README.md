# Jiangcheng Memory

Jiangcheng Memory is a model-independent, memory-native agent kernel and neurocognitive memory database.

The current branch implements the M1 trusted-storage foundation. Cognitive recall, runtime services, SDKs, models, and release artifacts remain scoped to later milestones and are not yet claimed as available.

See [README.zh-CN.md](README.zh-CN.md) for the primary project documentation.
